First-Principles Topology

        
Why 30 deep-and-thin layers beat wide-and-shallow baselines.

        

          Following empirical findings from MobileLLM (ICML 2024) and SmolLM2 (2025), sub-150M models suffer when parameter budget is squandered on wide 12-layer MLPs and bloated 50k+ token embedding tables. Rain v1.0 compresses vocabulary to a lossless 32,768 byte-level BPE table with tied input/output weights—reallocating 106.21M parameters into 30 sequential reasoning blocks.
        

      


      

        
        

          
01 / TURING SM75 GUARDRAIL

          
Per-Head QK-RMSNorm & Zero-Centered Gains

          

            Free-tier NVIDIA Tesla T4 GPUs lack native bf16 Tensor Cores. In standard 30-layer transformers, pre-softmax attention logits exceed the 65,504 ceiling of fp16. Rain normalizes Query and Key heads prior to RoPE rotation and computes zero-centered RMSNorm (y = x̂(1 + γ)) in f32, eliminating NaN divergence permanently.
          

        


        
        

          
02 / 3:1 GROUPED-QUERY ATTENTION

          
9 Query Heads / 3 KV Heads (d_head = 64)

          

            Each Key/Value head is shared across 3 Query heads, slashing autoregressive KV-cache memory by 3× compared to Multi-Head Attention while preserving full multi-subspace expressivity across a 2,048-token context horizon (θ = 100,000).
          

        


        
        

          
03 / DIGIT-ISOLATED BYTE BPE

          
Lossless UTF-8 & Arithmetic Token Splitting

          

            Built from scratch in rain-tokenizer without C++ regex dependencies. Every numeric digit (\p{N}{1}) is isolated into a dedicated token during pre-tokenization so multi-digit arithmetic never suffers from arbitrary subword merge boundaries.
          

        

      

    


    
    

      

        
Manifold Optimization

        
Hybrid Muon + AdamW

        

          Rain partitions its parameter store into two mathematically distinct optimization regimes:

            210 Matrices
            
    
              Muon (5-Step Quintic Newton-Schulz): Applied to all 2D hidden projection matrices (W_q, W_k, W_v, W_o, W_gate, W_up, W_down). Orthogonalizes Nesterov gradient momentum onto the Stiefel manifold with polynomial coefficients (3.4445, -4.7750, 2.0315) and Moonlight aspect-ratio scaling 0.2 * sqrt(max(m, n)), cutting optimizer VRAM by 50%.
            
    
          
    • 
          
  • 
            122 Tensors
            
    
              Decoupled AdamW: Applied exclusively to the tied 32,768 × 576 token embedding table and 1D zero-centered RMSNorm gain vectors.

O(1) Memory Data Pipeline

        
Bijective Feistel Shuffling & 13-Gram Decontamination

        

          Streaming directly from verified open-source Parquet repositories (ODC-By 1.0 / Apache 2.0), rain-data guarantees clean-room provenance:
        

        

          

            
DEDUPLICATION

            
XXH3-64 + 64-Perm MinHash LSH

            
16-band × 4-row shingle hashing eliminates near-duplicate web boilerplate.

          

          

            
DECONTAMINATION

            
13-Gram Benchmark Filter

            
Purges any document colliding with ARC, HellaSwag, PIQA, WinoGrande, or MMLU.

          

          

            
SHUFFLING

            
4-Round Cycle-Walking Feistel

            
Bijective index permutation over mmap shards with zero index-array RAM overhead.

          

          

            
COLAB FUSE BYPASS

            
NVMe Staging + SHA-256

            
Stages shards to local /tmp before mmap to eliminate Google Drive I/O stalls.

Cargo Workspace Architecture

        
Seven specialized Rust crates. Zero external bloat.

      


      

        

          
crates/rain-tokenizer

          
Byte-Level BPE & ChatML

          
32,768 vocabulary with parallel Rayon pair-frequency reduction, digit isolation, and lossless UTF-8 roundtrip verification.

        

        

          
crates/rain-data

          
Streaming Parquet & .rbin Packer

          
Direct HTTP Parquet reader, 13-gram benchmark decontaminator, XXH3 + MinHash deduplicator, and Feistel mmap loader.

        

        

          
crates/rain-model

          
30-Layer Deep-Thin Transformer

          
3:1 GQA, per-head QK-RMSNorm, RoPE (θ=100k), SwiGLU FFN, tied embeddings, and Z-loss regularized cross-entropy.

        

        

          
crates/rain-train

          
Hybrid Muon+AdamW & WSD Loop

          
5-step Newton-Schulz orthogonalizer, Dynamic FP16 LossScaler, and atomic SHA-256 SafeTensors checkpointing.

        

        

          
crates/rain-infer

          
KV-Cached Engine & Q8_0 Quantizer

          
Contiguous KV cache, Temperature / Top-K / Top-P / Min-P sampling with repetition penalty, and symmetric block-32 int8 quantization.

        

        

          
crates/rain-eval & rain-cli

          
Log-Likelihood Harness & CLI

          
Zero-shot multiple-choice evaluator, held-out perplexity calculator, and unified rain command-line interface.
